Data Management

⚠️ Important: Data Safety

Browser Cache Cleanup: The automatic backups stored in your browser's localStorage CAN be deleted when you clear browsing data/cache. They are NOT permanent storage.

Recommendation: Regularly export your data to a JSON file (stored on your computer/cloud) for true data safety. This is the ONLY way to protect against data loss from browser cache cleanup, browser crashes, or computer failures.

Export / Import

Export: Download all your data as a JSON file. The file will be automatically saved to your browser's Downloads folder.

Import: Restore data from a previously exported JSON file. This will replace ALL current data.

Automatic Backups (Browser Storage Only)

What are these? Automatic backups are saved in your browser's localStorage (same as browser cache). They provide quick recovery from accidental changes but are NOT safe from cache cleanup.

Limitations:

  • ❌ Cleared when you clear browser cache/data
  • ❌ Only accessible in this specific browser
  • ❌ Not accessible if browser crashes or is reinstalled
  • ❌ Cannot be accessed outside the browser
  • ✅ Good for: Quick undo of recent changes
  • ✅ Kept: Up to 10 most recent backups

How to Access localStorage (for debugging)

To view or extract your localStorage data outside the normal UI:

  1. Open your browser's Developer Tools (F12 or right-click → Inspect)
  2. Go to the "Application" tab (Chrome/Edge) or "Storage" tab (Firefox)
  3. Expand "Local Storage" in the sidebar
  4. Click on your site's URL
  5. Look for keys starting with "resource-planning-backup-"
  6. Copy the value and save it to a file if needed

📖 Glossary: FTE, PM, and %

Understanding the three units in this app:

FTE (Full-Time Equivalent) — Capacity
  • What: A person's work capacity/availability
  • Range: 0.0 to 1.0 (1.0 = full-time, 0.5 = half-time)
  • For a month: 1.0 FTE = 1 PM of capacity
  • Example: Someone working part-time has 0.5 FTE
PM (Person-Months) — Allocation (Source of Truth)
  • What: Amount of work allocated to a project
  • Unit: Person-months (time-based effort)
  • Source of truth: This is the primary value stored
  • Example: 0.5 PM = half a person's month of work
% (Percentage) — Utilization (Calculated)
  • What: How much of a person's capacity is used
  • Formula: % = (PM / FTE) × 100
  • Derived: Always calculated from PM and FTE
  • Example: 0.5 PM on 1.0 FTE = 50% utilization
  • Example: 0.5 PM on 0.5 FTE = 100% utilization
💡 Key Insight: PM is the single source of truth. FTE defines capacity, and % shows utilization. For a single month: 1.0 FTE = 1 PM of capacity
